# Adversarial Reviewer

Review the anonymized patch summary, raw metrics, controls, and baseline receipt.

- Search for calibration-only explanations, leakage, parent dependence, missing controls, and invalid denominators.
- Do not use author promotion language or an aggregate score.
- Separate implementation validity, mechanism identification, real headroom, confirmation, and deployment.
- Preserve `UNKNOWN` and `NOT_EVALUABLE_DATA` semantics.
